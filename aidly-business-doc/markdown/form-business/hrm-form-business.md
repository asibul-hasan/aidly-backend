# HRM Form Business

| Form | Name | How It Works |
| --- | --- | --- |
| HRM_1001 | Employee Management | Maintains employee master data, official/personal details, department/designation/grade, joining and active status. Can provision a linked login user where policy allows. |
| HRM_1002 | Department & Designation Setup | Maintains department hierarchy and designations. Department heads and designation attributes feed employee setup and approvals. |
| HRM_1003 | Shift Setup | Defines shifts, timing, grace rules, and attendance interpretation inputs. |
| HRM_1004 | Grade / Pay-Scale Setup | Maintains grades and pay scale bands used by employee/payroll setup. |
| HRM_1005 | Leave Type Setup | Defines leave categories, accrual behavior, carry-forward, and active status. |
| HRM_1006 | Holiday Calendar | Maintains branch/company holiday dates used by attendance and leave calculations. |
| HRM_1007 | Salary Component Setup | Defines earning/deduction components, calculation type, taxable/PF flags, and GL intent. |
| HRM_1008 | HR Policy / Settings | Stores HR policy switches and defaults used across attendance, leave, and payroll. |
| HRM_1101 | Manual Attendance | Allows authorized manual attendance entry/adjustment for employees and dates. |
| HRM_1102 | Device-Sync Attendance | Imports attendance punches from device data and maps them into attendance records. |
| HRM_1103 | Attendance Adjustment | Handles corrections and exception adjustments with auditability. |
| HRM_1104 | Shift Roster | Assigns employees to shifts by date/range for roster-driven attendance. |
| HRM_1105 | Overtime | Records and approves overtime and feeds payroll calculations. |
| HRM_1106 | Promotion / Transfer | Records employee designation/grade/department/branch movement. |
| HRM_1201 | Salary Structure Setup | Defines employee salary structure and component amounts/formulas. |
| HRM_1202 | Salary Processing | Runs payroll for a period, locks calculation results, and emits accounting events when posted. |
| HRM_1203 | Salary Sheet | Read/report view of processed payroll. |
| HRM_1204 | Payslip Generator | Employee payslip view/print/export from processed payroll. |
| HRM_1205 | Bonus / Festival | Processes bonus/festival payments and can emit financial posting events. |
| HRM_1206 | Loan / Advance | Records employee loans/advances and payroll recovery behavior. |
| HRM_1207 | Final Settlement | Calculates employee final settlement on separation. |
| HRM_1301 | Leave Application | Employee leave requests, approval state, and balance impact. |
| HRM_1303 | Leave Balance | Read/report view of leave entitlement, used, and remaining balance. |
| HRM_1401 | Job Requisition | Department hiring request and approval workflow. |
| HRM_1402 | Candidate / Application | Candidate profile, source, requisition link, and application status. |
| HRM_1404 | Offer & Onboarding | Offer approval/onboarding flow and optional employee creation. |
